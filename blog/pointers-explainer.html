What are Pointers?

Variables that store memory addresses — the most powerful (and feared) feature of C++.

01 — The Idea

Think of memory like a street of houses

Your computer's RAM is like a long street of numbered houses. Every variable lives at one address. A pointer is a variable that doesn't hold a value — it holds the address of another variable. It's like writing down someone's home address instead of moving into their house.

Normal Variable
🏠 The House itself

int age = 25;

The variable age is the house. It lives at some address in memory and holds the value 25 inside it.

Pointer Variable
📬 The House's Address

int* ptr = &age;

The pointer ptr doesn't hold 25 — it holds the address of where age lives. A signpost pointing to the house.

03 — The Syntax

3 symbols you must know

Pointers have 3 key operators. Confusing them is the #1 beginner mistake. Burn these into memory.

// ① & — "address-of" operator → get the address of a variable
int age = 25;
int* ptr = &age; // ptr now holds the ADDRESS of age (e.g. 0x7ffd4)

// ② * in declaration — means "this is a pointer"
int* ptr; // ptr is a pointer that will store an int's address
double* dptr; // pointer to a double
char* cptr; // pointer to a char

// ③ * in usage — "dereference" → get/set the VALUE at that address
cout << *ptr; // prints 25 (the value AT the address ptr holds)
*ptr = 30; // changes age to 30 — through the pointer!
cout << age; // prints 30 ← it really changed!
04 — Real C++ Examples

Where pointers actually show up

The most common use of pointers: letting a function actually change the caller's variable (not just a copy).

// ❌ Without pointer — function gets a COPY, original unchanged
void doubleIt(int x) { x = x * 2; } // only changes the copy!

// ✅ With pointer — function modifies the ORIGINAL
void doubleIt(int* x) {
  *x = *x * 2; // dereference: modify the real variable
}

int main() {
  int num = 10;
  doubleIt(&num); // pass ADDRESS of num
  cout << num; // Output: 20 ← actually changed!
}

In C++, an array name IS a pointer — it holds the address of the first element.

int scores[] = {85, 92, 78, 96};

// Array name is a pointer to first element
int* ptr = scores; // same as &scores[0]

cout << *ptr; // 85 (first element)
cout << *(ptr + 1); // 92 (second element)
cout << *(ptr + 2); // 78 (third element)

// Pointer arithmetic: ptr+1 moves 4 bytes forward (size of int)
ptr++;
cout << *ptr; // 92 — now pointing at second element

Use new and delete to allocate memory on the heap at runtime — pointers are the only way to access it.

// Allocate a single int on the heap
int* ptr = new int(42);
cout << *ptr; // 42

// Allocate an array of 5 ints on the heap
int* arr = new int[5];
arr[0] = 10; arr[1] = 20; // etc.

// ⚠️ ALWAYS free heap memory when done — or you get a memory leak!
delete ptr; // free single allocation
delete[] arr; // free array allocation
ptr = nullptr; // good practice: null out after delete

A pointer not pointing to anything valid is a null pointer. Always check before dereferencing — or your program crashes.

int* ptr = nullptr; // points to nothing (C++11 style)

// ❌ DANGER — dereferencing null crashes your program
// cout << *ptr; // Segmentation fault! 💥

// ✅ SAFE — always check first
if (ptr != nullptr) {
  cout << *ptr; // safe to dereference
} else {
  cout << "Pointer is null!" << endl;
}

// They manage memory automatically — less chance of bugs

06 — Key Concepts

The vocabulary you need

📍
Core
Address (&)

Every variable has a memory address. The & operator gives you that address.

👉
Core
Pointer (*type)

A variable that stores a memory address. Declared with *: int* ptr.

🔓
Core
Dereference (*ptr)

The * operator on a pointer — go to that address and get (or set) the value there.

🗑️
Safety
delete / nullptr

Always delete heap memory and set to nullptr after. Prevent leaks and dangling pointers.

💥
Error
Segfault

Accessing memory you don't own — dereferencing null or freed pointers. #1 C++ crash cause.

🧠
Modern C++
Smart Pointers

unique_ptr and shared_ptr manage memory automatically. Prefer these over raw pointers in modern C++.
