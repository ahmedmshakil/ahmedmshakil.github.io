Redis — In-Memory Database

Store data in RAM for sub-millisecond reads — caching, sessions, queues, and real-time leaderboards.

01 — The Idea

Disk is slow. RAM is fast. Redis is in RAM.

A traditional database reads from disk — milliseconds per query. Redis stores everything in RAM — microsecond reads. It's 1000x faster for the right use case. Redis is not a replacement for PostgreSQL; it's a layer in front of it: cache the hot data in Redis, persist everything in Postgres.

Request → Redis (RAM) → hit? return instantly ⚡
                    ↓ miss?
               PostgreSQL (disk) → fetch → store in Redis → return
02 — Data Structures

Redis supports rich data types

-- String: simple key-value
SET user:42:name "Alice"
GET user:42:name -- "Alice"

-- Hash: like a mini object
HSET user:42 name "Alice" age 28 city "Dhaka"
HGET user:42 name -- "Alice"

-- List: ordered (queue/stack)
LPUSH notifications:42 "You have a new message"
LRANGE notifications:42 0 9 -- last 10 notifications

-- Sorted Set: leaderboard!
ZADD leaderboard 9500 "Alice"
ZADD leaderboard 8200 "Bob"
ZRANGE leaderboard 0 2 WITHSCORES REV -- top 3

-- Expire key after 1 hour (cache TTL)
SET session:token "xyz123" EX 3600
03 — Common Use Cases
⚡
Most Common
Caching

Cache expensive DB query results with a TTL. Cache hit → instant response. Cache miss → fetch from DB, populate Redis.

🔐
Web Apps
Session Storage

Store user session tokens. Fast lookup, automatic expiry with EX. Shared across multiple app servers.

🏆
Gaming
Real-time Leaderboards

Sorted Sets maintain ranked data automatically. Add score, query top-N — all in O(log n) time.

🚦
API Security
Rate Limiting

INCR counter:user:42, check if > 100, reset with EXPIRE. Distributed rate limiting across all app servers.

📨
Architecture
Message Queue

LPUSH to enqueue, BRPOP to dequeue. Simple task queue without Kafka. Workers process jobs asynchronously.

💾
Persistence
RDB + AOF

Redis can persist to disk with snapshots (RDB) or append-only logs (AOF). Not as durable as Postgres but data survives restarts.
