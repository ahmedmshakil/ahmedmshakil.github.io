What is Async / Await?

Do multiple things at once without blocking — using std::future, std::async, and C++20's coroutines.

01 — The Idea

Think of it like ordering food at a restaurant

Synchronous means doing one thing at a time and waiting for each to finish before starting the next. Asynchronous means starting a task, then doing other things while it runs in the background — and checking back when it's done.

Synchronous (Blocking)
😴 The Impatient Chef
① Start boiling water...
② Wait... wait... wait (3 min)
③ NOW chop vegetables...
④ Wait... wait... wait (2 min)
⑤ NOW cook meat...
Total: 3+2+5 = 10 min 😩
Asynchronous (Non-Blocking)
⚡ The Smart Chef
① Start boiling water (async!)
② WHILE waiting → chop vegs
③ WHILE waiting → prep meat
④ Water ready? Cook everything!
⑤ —
Total: ~5 min 🚀

03 — The C++ Code

std::async and std::future

C++ uses std::async to launch a task asynchronously and std::future to get the result when it's ready — just like a ticket you cash in later.

#include <iostream>
#include <future> // for std::async, std::future
#include <thread> // for std::this_thread::sleep_for
#include <chrono>
using namespace std;

// A slow function — simulates a network call
string fetchUser() {
  this_thread::sleep_for(chrono::seconds(2)); // pretend network delay
  return "User: Alex";
}

int main() {
// ① Launch task ASYNC — runs in background, doesn't block future<string> result = async(launch::async, fetchUser);
  // ② Do other work while fetchUser() runs in another thread
  cout << "Doing other work..." << endl;
  cout << "Still doing work..." << endl;

// ③ .get() blocks ONLY when we actually need the result string user = result.get(); // "await" — wait here until ready cout << user << endl; // Output: User: Alex
  return 0;
}

Launch multiple tasks simultaneously — all run in parallel, dramatically reducing total time.

#include <future>
using namespace std;

int fetchUser() { sleep_for(2s); return 42; }
int loadImages() { sleep_for(1s); return 8; }
int getWeather() { sleep_for(1s); return 28; }

int main() {
  // All 3 launch simultaneously!
  auto f1 = async(launch::async, fetchUser);
  auto f2 = async(launch::async, loadImages);
  auto f3 = async(launch::async, getWeather);

  // Wait for all — total time ≈ 2s (the longest), not 4s
  cout << "User ID: " << f1.get() << endl; // 42
  cout << "Images: " << f2.get() << endl; // 8
  cout << "Temp: " << f3.get() << endl; // 28°C
}

Exceptions thrown inside async tasks are captured and re-thrown when you call .get().

string riskyFetch() {
  throw runtime_error("Network timeout!");
  return "data"; // never reached
}

int main() {
  auto future = async(launch::async, riskyFetch);

  // Do other work here...

  try {
    string result = future.get(); // exception re-thrown here
  } catch (const exception& e) {
    cout << "Error: " << e.what() << endl;
    // Output: Error: Network timeout!
  }
}

A promise is the sender; a future is the receiver. One thread sets the value, another waits for it.

#include <future>
#include <thread>
using namespace std;

void worker(promise<int>&& p) {
  // Do some work...
  this_thread::sleep_for(1s);
  p.set_value(42); // "fulfill" the promise
}

int main() {
  promise<int> p;
  future<int> f = p.get_future();

  thread t(worker, move(p)); // launch worker
  cout << f.get(); // blocks until worker calls set_value → 42
  t.join();
}

C++20 introduces coroutines — functions that can suspend and resume, making async code look synchronous.

// C++20 Coroutine (requires compiler support: -std=c++20)
#include <coroutine>
#include <iostream>

// co_await suspends the coroutine until the awaitable completes
// co_return returns a value from the coroutine
// co_yield yields a value and suspends (like a generator)

Task fetchAndPrint() {
  auto data = co_await fetchFromNetwork(); // suspend here
  cout << data << endl; // runs when data is ready
  co_return;
}

// co_await is C++'s true "async/await" syntax
// Similar to Python's async/await and JS's async/await
05 — Key Concepts

The vocabulary you need

🔄
Core
Synchronous

One task at a time. Each line waits for the previous to complete before running. Simple but slow for I/O-heavy work.

⚡
Core
Asynchronous

Tasks can start and run without blocking the caller. Your program stays responsive and does more in less time.

🚀
C++ Tool
std::async

Launches a function in a separate thread. Returns immediately with a future — a "receipt" for the result.

📬
C++ Tool
std::future

A handle for a value that isn't ready yet. Call .get() to block-and-wait when you actually need the result.

🤝
C++ Tool
std::promise

The "write side" of a future. One thread sets the value with .set_value(); another reads it via .get().

🧵
C++20
Coroutines

Functions that can pause (co_await) and resume. The cleanest async syntax in C++ — like async/await in Python.
